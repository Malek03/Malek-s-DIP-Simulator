# Vision Studio — منصة معالجة الصور الرقمية

Vision Studio (Malek Studio) هي منصة تعليمية تفاعلية مصممة لتبسيط المفاهيم المعقدة في مجال معالجة الصور الرقمية (Digital Image Processing). توفر المنصة بيئة محاكاة تفاعلية لفهم التحويلات الرياضية على مستوى البكسل، مع توليد فوري لأكواد بايثون (Python) باستخدام مكتبتي OpenCV و NumPy.

## 🌟 الميزات الرئيسية

- **محاكاة تفاعلية عبر Canvas**: قم برفع أي صورة وتطبيق الخوارزميات عليها بشكل مباشر ورؤية النتائج فوراً.
- **توليد كود تلقائي**: مع كل تغيير في المعاملات (Parameters)، يتم تحديث كود بايثون المقابل بشكل مباشر لنسخه واستخدامه في مشاريعك.
- **معالجة حية وتفاعلية**: عرض حي للصورة الأصلية والصورة المعالجة جنباً إلى جنب مع تحديث فوري للهيستوغرام (Histogram).
- **واجهة مستخدم عصرية**: تصميم متجاوب (Responsive) يدعم الوضعين الفاتح والداكن (Light/Dark mode) باستخدام Tailwind CSS.

## 🛠 التقنيات المستخدمة (Tech Stack)

تم بناء المشروع كواجهة أمامية (Frontend) بالكامل، مما يعني أنه لا يتطلب خادماً خلفياً (Backend) لعمليات معالجة الصور الأساسية المعروضة، بل يعتمد على تقنيات الويب الحديثة:

- **الواجهة والهيكلة**: HTML5
- **التصميم والأنماط**: Tailwind CSS (عبر CDN للتطوير السريع) و CSS مخصص.
- **المنطق ومعالجة الصور (Client-side)**: Vanilla JavaScript مع استخدام Canvas API لمعالجة البكسلات.
- **الخطوط**: Tajawal (للنصوص العربية) و JetBrains Mono (للأكواد).

## 🚀 كيفية البدء (Getting Started)

نظراً لأن المشروع يعتمد على تقنيات الواجهة الأمامية بالكامل، فإن تشغيله محلياً بسيط جداً.

### الخطوة 1: استنساخ المشروع
```bash
git clone <repository-url>
cd "Vision studio"
```

### الخطوة 2: تشغيل المنصة
هناك طريقتان لتشغيل المشروع:

**الطريقة الأبسط (مباشرة):**
قم بفتح ملف `index.html` مباشرة في أي متصفح ويب حديث (Google Chrome, Firefox, Edge).

**الطريقة الاحترافية (عبر خادم محلي):**
لتجنب مشاكل سياسة مشاركة الموارد (CORS) عند تحميل بعض الصور المحلية إلى الـ Canvas، يُفضل استخدام خادم محلي بسيط.
إذا كان لديك Python مثبتاً:
```bash
# Python 3
python -m http.server 8000
```
ثم افتح الرابط: `http://localhost:8000`

إذا كان لديك Node.js:
```bash
npx serve .
```

## 📚 الوحدات التعليمية المتاحة (Modules)

### 1. معالجة النقاط (Point Processing)
التحويلات الأساسية التي تعمل على كل بكسل بشكل مستقل:
- **الصور السلبية (Image Negatives)**: عكس قيم البكسلات.
- **التحويل اللوغاريتمي (Log Transformations)**: توسيع النطاق الديناميكي للقيم المظلمة.
- **تصحيح غاما (Gamma Correction)**: التحكم الدقيق بإضاءة الصورة.
- **العتبة (Thresholding)**: تحويل الصورة إلى ثنائية (أبيض وأسود).
- **تمدد التباين (Contrast Stretching)**: تحسين التباين في الصور الباهتة.
- **تقطيع المستوى البتّي (Bit-plane Slicing)**: تحليل الصورة إلى مستويات ثنائية لاستخراج التفاصيل.

### 2. أساسيات الصورة (Image Basics)
العمليات الهندسية على الصور مثل: التكبير/التصغير (Scaling)، التدوير (Rotation)، الإزاحة (Translation)، والقص (Cropping).

### 3. تمثيل الصورة (Image Representation)
تفكيك قنوات الألوان (RGB)، أخذ العينات (Sampling)، التكميم (Quantization).
