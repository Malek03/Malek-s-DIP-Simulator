حول مقرر معالجة الصور الرقمية

معالجة الصور الرقمية (Digital Image Processing) هي أحد أعمدة الرؤية الحاسوبية والذكاء الاصطناعي. يتناول هذا المقرر الأسس الرياضية والخوارزمية لتحويل الصور على مستوى البكسل، بدءاً من التحويلات النقطية (Point Processing) وصولاً إلى الترشيح المكاني والمعالجة المورفولوجية.

تتيح لك هذه المنصة التعلم عبر التفاعل المباشر مع كل خوارزمية: شاهد المعادلة الرياضية، جرّب المعاملات بنفسك على Canvas تفاعلي، واحصل على كود Python/OpenCV جاهز للتطبيق.

التحسين على مستوى البكسل

ستة تحويلات أساسية تعمل على كل بكسل بشكل مستقل — الأساس الذي تُبنى عليه كل تقنيات معالجة الصور.

الصور السلبية

Image Negatives

عكس قيم البكسلات — تحويل الأبيض إلى أسود والعكس. يُستخدم في تحليل الصور الطبية.

s = (L−1) − r
㏒

التحويل اللوغاريتمي

Log Transformations

توسيع النطاق الديناميكي للقيم المظلمة مع ضغط القيم المضيئة. مثالي لصور الطيف الترددي.

s = c · log(1 + r)
γ

تصحيح غاما

Gamma Correction

التحكم الدقيق بإضاءة الصورة عبر معامل القوة. يُستخدم في شاشات العرض وأنظمة التصوير.

s = c · rγ
T

العتبة

Thresholding

تحويل الصورة إلى ثنائية (أبيض وأسود) بناءً على قيمة حدّية. أساس تجزئة الصور.

s = 0 if r < T, else 255
⇔

تمدد التباين

Contrast Stretching

إعادة توزيع مستويات الرمادي عبر دالة خطية متعددة القطع لزيادة التباين.

Piecewise Linear: (r₁,s₁) → (r₂,s₂)
01

تقطيع المستوى البتّي

Bit-plane Slicing

تحليل الصورة إلى 8 مستويات ثنائية. المستويات العليا تحمل التفاصيل الأهم.

bitk = (pixel >> k) & 1

تصحيح غاما

            
Power-Law / Gamma Correction

          

        


        

          
المعادلة الرياضية

          

            s = c · rγ
          

          

            عندما γ < 1: يتم تفتيح الصورة (توسيع القيم الداكنة). عندما γ > 1: يتم تعتيم الصورة (ضغط القيم الداكنة).
            عند γ = 1: لا تغيير (تحويل الهوية).

تمدد التباين

            
Contrast Stretching

          

        


        

          
المعادلة الرياضية

          

            تحويل خطي متعدد القطع بنقطتَي تحكم:

            (0, 0) → (r₁, s₁) → (r₂, s₂) → (255, 255)
          

          

            النقطتان (r₁, s₁) و (r₂, s₂) تحددان شكل دالة التحويل. عندما s₁=0 و s₂=255 يكون التحويل أقرب إلى العتبة المزدوجة.
          

        


        

          
الاستخدامات العملية

          
    
            
  • •تحسين الصور ذات التباين المنخفض (كالصور الضبابية أو الباهتة)
    • 
            
  • •إبراز نطاق محدد من مستويات الرمادي مع ضغط البقية
    • 
            
  • •خطوة تمهيدية لعمليات التجزئة وكشف الحواف

تقطيع المستوى البتّي

            
Bit-plane Slicing

          

        


        

          
المعادلة الرياضية

          

            bitk = (pixel >> k) & 1
          

          

            كل بكسل 8-bit يمكن تحليله إلى 8 مستويات ثنائية (bit 0 إلى bit 7).
            المستوى bit 7 (MSB) يحمل أكبر قدر من المعلومات البصرية، بينما bit 0 (LSB) يحمل أقل تأثير.

    • 
            
  • •تحليل بنية الصورة الداخلية لفهم توزيع المعلومات
